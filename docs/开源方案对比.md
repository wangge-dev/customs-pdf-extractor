# 开源方案对比与改进方向

本文比较公开项目的功能与适用场景，资料核对日期为 2026-11-11。功能描述来自项目官方仓库；对本工具的判断基于现有实现。各方案没有使用同一组经人工标注的报关单进行对照，因此这里不比较识别成功率，也不推断谁的准确率更高。

| 项目 | 主要能力 | 对报关单场景的参考价值 | 许可与限制 |
| --- | --- | --- | --- |
| [pdfplumber](https://github.com/jsvine/pdfplumber) | 提取文字及字符坐标、线条和表格，提供表格识别的可视化调试 | 适合定位电子报关单的字段及检查版面；本工具已使用 | MIT；项目说明其更适合电子生成的 PDF，不能单独完成 OCR |
| [RapidOCR](https://github.com/RapidAI/RapidOCR) | 中文和英文 OCR，支持 ONNX 等推理方式及离线部署 | 可识别字段截图，与 PDF 文字层进行对照；本工具已使用 | 源码 Apache-2.0；具体模型还需查看上游来源、许可和署名要求。OCR 仍可能受印章、低清晰度和裁剪位置影响 |
| [Camelot](https://github.com/camelot-dev/camelot) | 表格提取，支持有线表格、空白分列等方法；官方说明可选装模型及 OCR 扩展 | 可试作另一套表格解析方法，验证表格边界及跨版式适应能力 | MIT；扫描件和部分模型功能需要额外依赖，是否适合多行表格、合并字段与中文报关单必须实测 |
| [DTOCR](https://github.com/Adamact/DTOCR) | 在示例 PDF 上绘制提取区域、保存模板、检测及调整表格网格，再导出 Excel | 新货代版式可借鉴“画框、预览、保存模板”的交互，减少改代码次数 | MIT；项目尚新，默认使用 TrOCR 印刷体模型，中文效果、复杂报关单适配和稳定性未经本项目验证 |
| [Docling](https://github.com/docling-project/docling) | PDF 版面、阅读顺序和表格结构解析，支持 OCR、图像及本地运行 | 可作为复杂版面和扫描件的候选方案，在实际样本上与现有方案做对照 | 代码 MIT，模型许可分别查看上游；依赖和运行资源需求需实际评估，并需开发报关单字段映射 |
| [OCRmyPDF](https://github.com/ocrmypdf/OCRmyPDF) | 为扫描 PDF 增加可搜索的文字层，集成 OCR 工具 | 可作为未来扫描件预处理的候选，需用目标语言和真实样本验证 | MPL-2.0；Tesseract、Ghostscript 等依赖各有许可及安装要求，本项目未集成 |

## 本工具已有能力

- 通用模式提供 PDF 批量体检、逐页文本、表格单元格与 JSON 自定义字段提取；保留相对路径、页码和异常提示，均基于文字层，未集成扫描件 OCR。
- 针对报关单提取收发件人、代码、合同、口岸及商品明细等字段，生成两份业务 Excel，并支持多文件、子目录和多页处理。
- Windows 图形界面可选择输入和输出文件夹；完整打包版可在不安装 Python 和 Codex 的环境使用。
- 同时保留 PDF 文字提取、字段截图 OCR、规则提示、核对报告和原图核对页面，便于回到来源检查。
- 对已适配版式中的紧邻商品编号及名称、境内货源地与相邻文字等情况做了专门处理。

这些优势是针对既定报关单工作流的功能设计，并不代表底层识别技术优于上述开源项目。PDF 文字和 OCR 可能同时定位到错误位置；漏掉整行也可能未被字段级对照发现。扫描件、文字层异常、遮挡、未知版式及附页仍须特别注意。核对报告填写人工确认值后，不会自动回写业务表。

## 可按需推进的方向

1. **版式适配**：参考 DTOCR，探索可视化框选和模板配置，并明确无法识别版式时如何提示；新增模板必须经过真实样本验证。
2. **核对体验**：将异常字段、截图和人工修改放到同一流程中，并明确何时保存或导出已修改结果；保留原始读取值供复查。
3. **完整性检查**：增强对商品项号、页码、附页和空字段的提示；区分“程序没有发现问题”和“人工已确认”。
4. **第二解析方法**：以 Camelot 或 Docling 做候选，使用经授权的脱敏样本比较字段正确率、漏项、运行时间和资源占用，再决定是否引入。
5. **扫描件**：先识别缺少文字层的页面并提示现有能力限制，再在真实扫描样本上评估独立 OCR 流程，避免将普通字段截图识别误称为完整扫描件支持。

引用或分发第三方代码、模型及运行库时，应分别遵循其许可证和署名要求；本文所列项目源码许可不自动覆盖所有模型或传递依赖。
