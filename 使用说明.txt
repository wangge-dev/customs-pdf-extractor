本地 PDF 批处理与核对工具 使用说明

一、首次准备
1. 适用于 Windows 电脑，无需安装 Codex 或 Python。将收到的工具压缩包完整解压到电脑本地文件夹，不要直接在压缩包里运行。
2. 打开解压后的工具文件夹，双击“本地PDF批处理.exe”。程序文件和同目录的“_internal”文件夹必须放在一起；转交同事时，请发送完整工具文件夹或其压缩包，不要只发送 exe。源码仓库不直接包含该程序包，需要先按 README 构建。
3. 将要处理的 PDF 放到一个文件夹中。如原文件是 RAR 等压缩包，请先完整解压；程序会处理所选文件夹及其子文件夹内的 PDF。

二、开始提取
1. 在“PDF 文件夹”一栏点击“选择文件夹”，选择存放 PDF 的文件夹。
2. 在“结果保存到”一栏点击“选择文件夹”，选择一个已有文件夹，作为保存位置。
3. 选择处理模式：PDF 体检及文本导出、PDF 表格提取、自定义字段提取或报关单提取。字段提取需选择 JSON 规则，示例见源码中的“示例字段模板.json”。通用模式的结果目录请选择输入目录以外的文件夹。
4. 点击“开始提取”。下方会显示处理进度；处理期间请等待结束，并保持输入 PDF 可访问，不要移动、删除或重命名。数量较多时需要等待。
5. 显示处理结束后，可点击“打开通用结果表”，或在报关单模式下点击“打开核对报告”“打开原图核对”。“打开结果文件夹”可查看本次全部结果。每次运行都会新建目录，不覆盖之前的结果。

三、查看和核对结果
通用模式的体检表列出各文件、页数、文字层与文本导出状态；逐页文本保留原有子目录。表格结果按页、表、行、列记录；自定义字段结果保留页码、原文片段和待核对项。无文字层页面没有执行 OCR；表格和字段都可能漏提或错提，请对照原 PDF。

报关单模式的结果目录包含：
• “预录单收发件人信息.xlsx”：每份 PDF 的收发件人等信息。
• “预录单商品明细提取.xlsx”：每个商品项目的明细。
• “提取核对报告.xlsx”：文件总览、优先核对、全部字段核对和规则核对等。
• “逐字段原图核对.html”：双击用浏览器打开，可按文件名、字段、核对状态或编号筛选；没有截图时请查看原 PDF。
• “本次运行结果.txt”：本次文件数量和结果位置。

先查看核对报告的“文件总览”“优先核对”和“规则核对”，对照原图或原 PDF 处理待核对项目；其他机器一致项目也应抽查。报告中可填写“人工确认值”和“复核意见”。这些填写或核对标记不会自动修改两张业务表；如需更正，请核对后直接修改对应业务表并保存。“OCR 未完成文件数”包括部分字段没有得到有效 OCR 读数的文件；并不一定是整份文件识别失败。请在核对报告的“优先核对”中查看具体字段，并对照原 PDF。报关单之外的附页如未提取，会在规则核对中提示；请确认附页是否还有需要提取的商品。

四、适用范围和异常处理
本工具针对与样本版式相近、具有可提取文字层的报关单。扫描件、不同版式、手写或图像修改、缺页和文字层异常等情况可能提取不完整或定位错误，应对照原 PDF 逐项核对。“两路一致”是指 PDF 的文字读取结果与对应截图的识别结果相同；如果两次都取错同一行，或者整行漏掉，依然可能出错。请核对商品总项数，并对照原 PDF 抽查关键字段。
如提示没有找到 PDF，请检查是否已解压，以及是否选中了正确的文件夹；如处理报错，请保留界面中的错误信息和原 PDF，交给工具提供者排查。不要把识别结果直接当作已人工确认的数据。
